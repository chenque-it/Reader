使用说明：

说明：本版本为纯本地版本，不含在线小说、Web 阅读、网络代理和版本更新检测等联网功能。

一、快捷键 (可以在菜单【设置】 > 【按键设置】，进行自定义)
1.  F12：     隐藏/显示边框
2.  F11:      全屏/退出全屏
3.  Esc:      退出全屏
4.  Ctrl + O：打开新文件
5.  Ctrl + F: 全文关键字查找，并跳转到指定位置
6.  Ctrl + T：置顶/取消置顶
7.  Ctrl + G: 全文进度百分比跳转
8.  Ctrl + →：快速跳转到下一章
9.  Ctrl + ←：快速跳转到上一章
10. →：       下一页
11. ←：       上一页
12. ↑：       向上滚动 N 行 (N: 菜单【设置】 > 【基本设置】 > 【文本滚动速度】，默认为1)
13. ↓：       向下滚动 N 行 (N: 菜单【设置】 > 【基本设置】 > 【文本滚动速度】，默认为1)
14. Ctrl + 鼠标滚轮：调节窗口透明度
              向上滚动：透明度变低
              向下滚动：透明度变高
15. Ctrl + Shift + 鼠标滚轮：调节窗口透明度
              向上滚动：透明度直接最低(alpha = 0xff)
              向下滚动：透明度直接最高(alpha = 0x01)，基本全透明
              (！！无边框时对窗口做了特殊处理：1. 支持看起全透明(alpha=1)  2. 支持背景透明，字体不透明)
              (！！有边框时暂不支持上面功能。)
16. Alt + 鼠标滚轮：调节字体透明度，在无边框时体现
              向上滚动：透明度变低
              向下滚动：透明度变高
17. 空格键：  开始/停止自动翻页 (菜单【设置】 > 【基本设置】 > 【自动翻页时间间隔】，默认为3000ms)
              点击菜单选项时，会自动暂停“自动翻页”，菜单完成后会自动恢复“自动翻页”
              书本翻到最后一页会自动停止“自动翻页”
              自动翻页可以设置【翻页】与【滚动】两种模式
18. 鼠标左右键同时按下：快速隐藏窗口，效果与热键 Alt + H 相同
              注意：隐藏后，需要使用热键 Alt + H 才能再次显示
	          可以在菜单【设置】 > 【基本设置】 > 【左右键同时按下隐藏窗口】开启/关闭此功能
19. Ctrl + M: 添加书签。（每本书最大支持256个书签）
              菜单栏 > 【书签】可以显示书签列表
              在书签列表项上面鼠标右击，可以删除书签
20. Ctrl + E: 进入编辑模式，可以用于文本复制，和简单编辑操作
21. Ctrl + -: 字体缩小
22. Ctrl + =: 字体放大
23. Ctrl + Alt + Shift + P: 开启/关闭“鼠标移出窗口，自动隐藏功能”

二、热键
1.  Alt + H： 快速隐藏/显示窗口 (可以在菜单【设置】 > 【按键设置】，进行自定义)

3.  鼠标向上滚动：上N行 (N: 菜单【设置】 > 【基本设置】 > 【文本滚动速度】，默认为1)

四、其他设置
1.  菜单【设置】 > 【显示设置】：
    1.1. 字体（包括字体大小和字体颜色）
    1.2. 背景颜色
    1.3. 背景图片：对于不规则的小图，建议设置背景模式为“旋转平铺”，效果更佳
    1.4. 字距、行距、段距、内部边框距。
    1.5. 目录字体跟随文本：当感觉目录字体小，看不清楚时可以启用该设置。
    1.6. Word wrap：当阅读英文文档时，请勾选此项设置。
    1.7. 首行缩进：在段落的开头添加两个全角空格。
    1.8. 压缩空行
    默认配置为：行距+段距+首行缩进+压缩空行，这样配置无论原文本排版如何，都可以有较好的显示效果。
2.  菜单【设置】 > 【按键设置】：    可以自定义快捷键和热键
3.  菜单【设置】 > 【高级设置】：    可以自定义Txt文本目录解析格式
                                     正则表达式样例：第.*章\s+.*
4.  菜单【设置】 > 【还原默认设置】：还原默认设置

五、其他说明
1.  如果需要还原软件最原始的状态或者软件出现异常无法启动：
    请删除Reader.exe同级目录下面的 “.cache.dat” 文件。
    该文件为隐藏文件。
    至于如何显示隐藏文件，请自行百度。
2.  四种新文件打开方式：
    2.1 Ctrl + O
    2.2 菜单：File > Open
    2.3 文件拖拽
    2.4 设置reader为指定文件类型默认打开方式
3.  删除某本书籍阅读记录：
	3.1 在菜单【文件】，鼠标右键单击该本书籍。
4.  边框隐藏时，鼠标左键按住页面顶部，可以进行拖动

五、FAQ (常见问题解答)
1. F12不能隐藏边框
答：如果是笔记本的话，可能Fn lock了，请尝试使用 Fn + F12，如果还不行，可以至【设置】>【按键设置】内重新设置【隐藏/显示边框】快捷键

2. 英文单词换行问题
答：请至【设置】>【基本设置】内勾选【Word wrap】

3. 打开小说后出现乱码
答：本软件会自动识别txt编码格式，如果出现乱码，请尝试【设置】>【字体设置】内重新设置字体。如果还有问题，请把文档和问题发我邮箱binbyu@qq.com

4. 设置字体后出现文字竖向排版
答：请重新设置字体，不要选择 @ 符号开头的字体

5. 软件报毒问题
答：本软件为开源软件，不存在病毒。由于没有花钱购买证书，部分杀毒软件会误报，属于正常现象
